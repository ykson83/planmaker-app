# API 계약

이 문서는 구현된 API와 합의된 API 계약을 기록한다. 계획 상태의 항목은 구현 완료로 간주하지 않는다.

## 구현됨

### `GET /health`

```json
{"status":"ok"}
```

## 계획됨

### 인증

- `POST /auth/signup` — 이메일, 닉네임, 비밀번호로 회원가입하고 로그인 세션을 만든다.
- `POST /auth/login` — 이메일과 비밀번호로 로그인 세션을 만든다.
- `GET /me` — 현재 로그인 사용자를 반환한다.
- `POST /auth/logout` — 현재 세션을 폐기한다.
- 초기에는 이메일·비밀번호 인증을 사용하고 OAuth는 후속 기능이다.
- 로그인 상태는 `HttpOnly` 세션 쿠키로 유지한다. 상태 변경 요청의 CSRF 방어 방식은 endpoint 구현 시 함께 명시한다.

### 약속

- 약속 생성, 조회, 수정, 취소
- 약속 참여자 초대
- 가입자 닉네임 검색 및 미가입자용 초대 링크 생성·폐기·참여 확인
- 참여 수락·거절
- 생성자만 수정·취소·초대할 수 있으며, 취소된 약속은 조회 전용이다.

### 알림

- 인앱 알림 목록 조회
- 알림 읽음 처리
- 초대, 참여 응답, 링크 참여, 약속 수정·취소에 대한 알림을 생성한다.

각 endpoint의 HTTP 메서드, 경로, 요청·응답 모델은 구현을 시작할 때 이 문서에 확정한다.
