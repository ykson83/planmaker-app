# API 계약

이 문서는 구현된 API와 합의된 API 계약을 기록한다. 계획 상태의 항목은 구현 완료로 간주하지 않는다.

## 구현됨

### `GET /health`

```json
{"status":"ok"}
```

## 계획됨

### 인증

- OAuth 로그인 시작
- OAuth callback 처리
- 첫 로그인 닉네임 설정
- 현재 로그인 사용자 조회
- 로그아웃

### 약속

- 약속 생성, 조회, 수정, 취소
- 약속 참여자 초대
- 참여 수락·거절

### 알림

- 인앱 알림 목록 조회
- 알림 읽음 처리

각 endpoint의 HTTP 메서드, 경로, 요청·응답 모델은 구현을 시작할 때 이 문서에 확정한다.
